# SOMMA — Landing page

Landing page institucional da SOMMA, construída com HTML, CSS e JavaScript puros.

## Executar localmente

Na raiz do projeto, inicie um servidor HTTP:

```bash
python3 -m http.server 4173
```

Depois acesse [http://localhost:4173](http://localhost:4173).

## Estrutura

- `index.html`: conteúdo e estrutura semântica da página.
- `styles.css`: identidade visual, componentes e responsividade.
- `script.js`: menu móvel, animações e ano automático do rodapé.
- `assets/`: arquivos visuais da marca.

Não há etapa de build nem dependências obrigatórias para produção.
